# Recommender Systems Assignments

This repository contains a collection of assignments completed during a Master's-level course in Recommender Systems at the **University of Fribourg**, as part of the [Swiss Joint Master in Computer Science](https://mcs.unibnf.ch/).

The work was carried out under the instruction of **PD Dr Luis Terán**.

---

## Overview

This repository showcases hands-on experience with core recommender systems techniques, combining theoretical understanding with practical implementation.

Covered topics include:

- Taxonomy of Recommender Systems
- Content-Based Filtering
- User-User Collaborative Filtering
- Item-Item Collaborative Filtering

All assignments are implemented in Python using Jupyter notebooks, with a focus on clarity, reproducibility, and structured analysis.

---

## Assignments

1. **Taxonomy of Recommender Systems**
2. **Content-Based Filtering**
3. **User-User Collaborative Filtering**
4. **Item-Item Collaborative Filtering**
